## Purpose

This repository stores the code I write while studying programming fundamentals. It has three parts: the C# language, object-oriented design, and data structures with algorithms.

Each topic is added after I study it. The commit history shows the order in which I learned each topic.

## How to Run

Requirements: [.NET SDK](https://dotnet.microsoft.com/download)

```bash
git clone https://github.com/iamsiamhossen/FundamentalAndDsa.git
cd FundamentalAndDsa/C-sharp
dotnet run
```

Each folder has its own examples. Open the folder of the topic you want and run it in the same way.

## Study Method

1. Read the concept and write short notes.
2. Write the code myself and test it with small inputs.
3. Compare the result with a hand-made answer.
4. Commit with a message that names the topic.
